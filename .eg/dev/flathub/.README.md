# flathub

## Running the workload

```bash
GH_TOKEN="$(gh auth token)" eg compute local --secret gcpsm://retrovibed-prod/flathub-env --gcp-auto -e GH_TOKEN dev/flathub
```

## What it does

Submits the current release to Flathub: forks `flathub/flathub` on GitHub, downloads the released `space.retrovibe.Console.yml` manifest, updates the flatpak assets in the fork, commits, and opens a submission PR.
