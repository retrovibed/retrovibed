# Linux Local Development Setup

## Prerequisites

### EG Build Tool

See https://egdaemon.com/docs/installation/index.html

### Java sdk

See your distro for installation instructions. version recommended: 21.

### android sdk

See your distro for installation instructions. flutter doctor must show android as configured.

## Running the application

```bash
eg compute baremetal --ttl=infinity dev/console/android
```
